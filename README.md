# Bazar Viral

Primera versión funcional del bazar de productos virales: portada adaptable, catálogo navegable, buscador, filtros, fichas individuales, favoritos persistentes, carrito local, Comunidad Viral, espacios y paneles por rol, administración y asistente demostrativo de campañas.

## Abrir localmente

Abre `index.html` en un navegador. No requiere instalación, cuenta ni servicios de pago.

## Estado

Esta versión utiliza contenido demostrativo. Vendedores pueden preparar su perfil y primer producto; creadores pueden conocer campañas, atribución y vincular un video de prueba. Nada se publica ni procesa pagos. La conexión real de cuentas, datos, campañas y pagos se incorporará después de validar la experiencia.
