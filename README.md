# Bazar Viral

Primera versión funcional del bazar de productos virales: portada adaptable, buscador, categorías, catálogo demostrativo, favoritos, carrito local y presentación de Comunidad.

## Abrir localmente

Abre `index.html` en un navegador. No requiere instalación, cuenta ni servicios de pago.

## Estado

Esta versión utiliza contenido demostrativo. Los flujos de registro, pagos, vendedores y creadores se incorporarán por etapas después de validar la experiencia pública.
